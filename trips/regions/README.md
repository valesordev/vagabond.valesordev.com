# Camping Region Catalog

Personal trusted reference for dispersed camping areas. Built from research,
trip reports, and field experience. Not a substitute for checking current
conditions before any trip — fire restrictions, road closures, and water
availability change constantly.

---

## Status Legend

- **Verified** — personally visited and confirmed
- **Researched** — sourced from trip reports, iOverlander, BLM/NPS resources; not yet field-tested
- **Planned** — on the radar, minimal research done

## How This Catalog Is Organized

Each region has a directory containing:
- `index.md` — region overview, rules, seasonal notes, logistics, and area index
- One `.md` file per distinct camping area or zone

Each area file covers:
1. **Overview** — character, location, land management
2. **Access & Road Conditions** — road type, clearance, seasonal closures, airing-down
3. **Site Quality** — shade, wind, views, flat ground, privacy
4. **Logistics** — fuel, water, cell service, Starlink viability, bail-out routes
5. **Trip History** — personal visit log with dates and field notes

## Check Before Every Trip

- [NPS Mojave — Fire & Alerts](https://www.nps.gov/moja/planyourvisit/conditions.htm)
- [BLM Recreation Map](https://www.blm.gov/maps)
- [Recreation.gov](https://www.recreation.gov) — permit availability (Inyo NF, etc.)
- [USFS Road Conditions](https://www.fs.usda.gov) — seasonal closures
- [CalTrans Quickmap](https://quickmap.dot.ca.gov) — highway pass conditions
- [NOAA Point Forecast](https://www.weather.gov) — desert heat, flash flood risk
- [iOverlander](https://www.ioverlander.com) — community campsite reports
