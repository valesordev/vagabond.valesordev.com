# Vagabond Documentation

Documentation for the Vagabond application repository. Start here when contributing features or reviewing architecture.

## What lives where

| Section | Purpose |
|---------|---------|
| [Architecture Decision Records](adr/) | Accepted (and proposed) technical decisions. Required before changing domain model, API shape, or infrastructure. |
| [User stories](user-stories/) | Buildable product stories with acceptance criteria, linked to ADRs. Start with [v0.1](user-stories/v0.1/). |
| [Runbooks](runbooks/) | Operator how-tos (PMTiles, Compose profiles, auth, edge). Index only for now; bodies TBD. |

Contributor workflow and coding standards: [CONTRIBUTING.md](../CONTRIBUTING.md).

Product interview notes and later release slices (v0.2+) still live in the parent planning repo (`life.solo7.media/vagabond/story-map-interview.md`) until promoted into `docs/user-stories/`.
